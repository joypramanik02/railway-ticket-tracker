# 🚆 Railway Ticket Tracker — Bangladesh Railway

Search Bangladesh Railway trains, compare sample fares by class, check demo seat availability, and save trips and seat alerts — all in the browser, no backend.

Built by **Joy Pramanik**, final-year CSE student at Southeast University, Dhaka, using HTML, CSS and JavaScript.

## Live preview

Open `index.html` in a browser, or enable GitHub Pages from this repository (Settings → Pages → Deploy from branch → main).

## What's inside

- `index.html` — Search form, popular routes, My Trips, seat alerts, About
- `style.css` — Responsive styling, no framework needed
- `script.js` — Sample timetable, fare calculator, seat-availability demo, localStorage trips & alerts

## Features

- Search by From / To station, date, class and passengers
- Popular routes in one tap: Dhaka ↔ Rajshahi, Dhaka ↔ Rangpur, Dhaka ↔ Bogura (Santahar), Dhaka ↔ Chattogram
- Sample fares by class: Shovon, Shovon Chair, AC Chair, Snigdha, AC Berth
- Demo seat status: Available / Few left / Waiting list, plus off-days per train
- Save trips and set seat alerts — stored in localStorage, nothing is sent to a server

## ⚠️ Important

This is a **demo** — the timetable and fares are samples for learning. Always check live availability and fares on the official site before you buy: https://eticket.railway.gov.bd/
